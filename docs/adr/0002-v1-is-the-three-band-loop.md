# v1 is the three-band loop, not a clinic directory

v1 is one phone-shaped client. A member opens an account, records a check-in, is placed on one band (early, mid, or late), reads a short menu for that band, and can look back at earlier check-ins. On the late band they can file an introduction. The introduction is recorded even when no clinic is available. There is no directory to browse.

A clinic directory was the obvious first product, because that is what "the NerdWallet of hair clinics" sounds like, and it is what RealSelf already is. It was rejected. Without the path from a cheap first step to a late introduction, Seenmark is a listing site with no reason for a clinic to pay for anything but an ad. A questionnaire with no photo was rejected for the same reason: the check-in is what makes a later introduction specific.

Native and web both shipping in v1 was rejected. One client. Which Better-t-stack preset implements that client is the user's choice, made before anyone scaffolds.
