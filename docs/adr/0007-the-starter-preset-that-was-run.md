# The starter preset that was run

The monorepo was created with Better-t-stack on 22 September 2026: Next and a bare Expo app, Hono on Node, tRPC, Drizzle, Postgres on Neon, Better Auth, Biome, Turborepo, pnpm, deployed toward Vercel. The reproducible command is in `bts.jsonc`.

That is wider than a single phone client. Both frontends stay, because that is the tree that was generated. Polar was in the scaffold. v1 still does not charge the member and does not charge a clinic, so on 24 September 2026 the Polar plugin, its client plugins, and its required configuration were removed rather than left registered and unused. Bringing payments back starts from a later decision that turns a paid link or a clinic fee into something that actually runs.
